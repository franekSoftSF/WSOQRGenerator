Every parameter this tool can write — reference, English only

A device-owner QR code is a small JSON document. Android reads it on a freshly reset device, downloads the management app named inside it and hands over the rest of setup — which is why a wrong character means a device that has already been wiped and now will not enrol.

Android provisioning extras (all prefixed android.app.extra.):

PROVISIONING_DEVICE_ADMIN_COMPONENT_NAMEWhich management app takes ownership. Always present.
PROVISIONING_DEVICE_ADMIN_SIGNATURE_CHECKSUMSignature the downloaded app must match.
PROVISIONING_DEVICE_ADMIN_PACKAGE_DOWNLOAD_LOCATIONWhere the device fetches that app from.
PROVISIONING_ADMIN_EXTRAS_BUNDLEEverything the management app itself needs — see the next table.
PROVISIONING_WIFI_SSIDNetwork name. Written only when you put WiFi in the code.
PROVISIONING_WIFI_PASSWORDNetwork password. Omitted for an open network.
PROVISIONING_WIFI_SECURITY_TYPEWPA, WEP or NONE.
PROVISIONING_WIFI_HIDDENNetwork that does not broadcast its name.
PROVISIONING_WIFI_PROXY_HOST / _PORT / _BYPASSManual proxy for the enrollment network.
PROVISIONING_WIFI_PAC_URLProxy auto-config URL — the alternative to a manual proxy.
PROVISIONING_LOCALELanguage and region, e.g. pl_PL.
PROVISIONING_TIME_ZONEOlson time zone, e.g. Europe/Warsaw.
PROVISIONING_SKIP_ENCRYPTIONDo not force encryption during setup.
PROVISIONING_LEAVE_ALL_SYSTEM_APPS_ENABLEDKeep the manufacturer's factory apps instead of disabling those outside the managed set.

Android accepts a few more that this page does not write — a download cookie header, a local time value, EAP WiFi details. The payload box is editable, so anything else can be added by hand.

Workspace ONE admin extras bundle:

serverurlDevice Services address the Hub reports to.
gidGroup ID — or the enrollment token, when registration is token-based.
un / pwStaging account. Both optional: leave the password out and the device asks for it, so it never travels in a printed code.
useUEMAuthenticationtrue keeps sign-in with the UEM console itself; false hands it to Workspace ONE Access (VIDM). Which one works depends on how the tenant is set up.
enable3rdPartyCookiesInVIDMAllows third-party cookies in the web view used for Workspace ONE Access sign-in — some identity providers need it.

Android Management API: the bundle carries com.google.android.apps.work.clouddpc.EXTRA_ENROLLMENT_TOKEN. Everything else about the token — the policy applied on enrollment, how long it stays valid, whether it works once only, whether personal usage is allowed, and up to 1024 characters of your own additionalData that comes back on the device as enrollmentTokenData — is decided when the token is created in the console or through the API, not in the QR code.
